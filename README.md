# Aishwarya_GEN_AI

## Mini Project

This project contains:
- AI Chatbot
- Blog Generator
- Email Generator


Open:
`ChatBot_Aishwarya.ipynb`

## Technologies Used
- Python
- Gemini AI
- Jupyter Notebook

## How to Run

```bash
pip install google-generativeai
jupyter notebook
```

Add Gemini API key and run all cells.

The chat bot will repond to the user's questions.
